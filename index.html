Knowledge compression for session-level RAG ACL workshop

Sep 2025 – Mar 2026
Retrieval · research

RAG knowledge bases grow redundant over time. This project reorganizes them by how often facts are retrieved together, so one retrieval can cover a whole user session.

  • Built an end-to-end pipeline that generated 62K QA pairs with GPT models for retrieval evaluation
  • Clustering-based compression shrank the knowledge base by 80% while raising weighted recall +6.8% and accuracy +10.9%
  • Trained custom Word2Vec embeddings on agent-generated QA sequences, with vector indexing for scale
